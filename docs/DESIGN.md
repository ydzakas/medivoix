# Design

Interface clinique en français, mobile d'abord, police Inter.

Le fond de page est un gris très clair. Les blocs sont des cartes blanches, aux coins arrondis, avec une bordure fine et une ombre légère. La barre du haut est blanche et reste visible au défilement. Le marine porte le texte et le nom. Le vert marque l'action principale, la validation et le micro qui écoute.

## Couleurs

| Rôle | Valeur |
| --- | --- |
| Marine, texte | `#0B2A4A` |
| Marine profond, hero | `#102C4C` |
| Vert médical | `#1E9E6A` |
| Vert appuyé | `#167C52` |
| Blanc, cartes | `#FFFFFF` |
| Fond de page | `#F4F7FB` |
| Fond de champ | `#F8FAFC` |
| Bordure | `#E6EDF5` et `#D5E0EC` |
| Texte secondaire | `#3E5168` |
| Fond vert léger | `#E7F6EF` |

Les cibles tactiles font au moins 44 px. Le micro qui écoute reste vert. Le texte reconnu en cours est en marine italique, avec un filet vert.
